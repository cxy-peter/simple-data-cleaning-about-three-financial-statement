## 如何开始

进入 qiming_agent 目录。安装 Python 3.11+ 后：

Windows：双击 start_local.bat。它创建虚拟环境、安装依赖并运行本机服务；初次安装需要网络。脚本尚未在真实 Windows 系统验收。

macOS/Linux：运行 sh start_local.sh。

打开 http://127.0.0.1:8765 。默认不调用外部模型，不上传数据。三个公开演示身份只供本机展示，不能直接用于公网部署。
